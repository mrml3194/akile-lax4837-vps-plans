## 原生 IP、双 ISP、4837 和 9929，哪个才是你该关心的

这三组词经常被混在一起卖，实际回答的是两个完全不同的问题。

**IP 属性解决「平台怎么看你」。** 原生 IP 指 IP 段的归属登记和机房所在地一致，洛杉矶机房分到加州段，平台查出来是本地地址，不是某云厂商的机房段。双 ISP 再进一层：ASN 和 Company 字段被识别成运营商或住宅宽带属性，风控更松。Akile 的 LAX4837 系列把「原生 IPv4」和「双 ISP」两个标签都标上了。

**线路解决「国内访问快不快」。** 4837 是联通 AS4837（CUVIP），9929 是联通 AS9929（CUII，精品网，地位大致相当于联通版的 CN2 GIA），CN2 GIA 是电信的精品线路。这些跟 IP 是不是原生没有关系，买的时候要分开看：你要的是不被判定成机房 IP，还是晚高峰回国不绕路，或者两者都要。

Akile 这条线是 4837 回程，属于联通优化线路，不是 9929。官方产品页提供了 Looking Glass 工具，可以自己测延迟和路由，公开资料里没有可核验的三网延迟实测数字，我不替它编一个。买之前花十分钟 ping 一下测试 IP，比看任何评测都直接。

还有一点值得说清楚：双 ISP 提升的是「被识别成本地住宅用户」的概率，不等于永久免疫。平台风控是动态的，某个 IP 段被滥用一段时间后照样会降级。
